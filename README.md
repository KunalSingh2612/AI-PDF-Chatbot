# ⚡ DocuMind AI – Premium GenAI Document Assistant

DocuMind AI is a next-generation, high-performance conversational AI tool designed to extract intelligent insights instantly from any PDF document. Built for elite performance and a frictionless user experience, it features a highly customized, premium dark-mode interface tailored for UI/UX excellence.

🚀 **[Live Demo on Hugging Face](https://bit.ly/4aF8CGD)** *(Note: Replace this link with your actual space link)*

---

## ✨ Key Features

- **Premium UI/UX Aesthetics:** Designed a custom, minimal dark-mode workspace by overriding the native Streamlit UI layout.
- **Clean Dropzone Layout:** Re-engineered the file upload component into a center-aligned, dashed-border container, eliminating distracting default platform constraints (hidden file size limits and system labels).
- **Advanced Context Retrieval:** Utilizes **LangChain** for robust document chunking and text extraction via `PyPDF2`.
- **State-of-the-Art LLM Integration:** Powered by **Google Gemini 1.5 Flash API** for instantaneous, context-aware question answering with an sub-second response time.
- **Secure Architecture:** Built with secure backend environment configurations to safeguard corporate API keys.

---

## 🛠️ Tech Stack

- **Frontend & Design:** Streamlit, Embedded CSS3, HTML5 (Inter Font & Premium Gradients)
- **AI & Orchestration:** LangChain, Google Generative AI API (`langchain-google-genai`)
- **Backend & PDF Parsing:** Python 3.10+, PyPDF2, OS Environment Secrets
- **Deployment:** Hugging Face Spaces (Streamlit SDK Cloud)
